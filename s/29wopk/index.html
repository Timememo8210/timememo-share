01 / Market

市场不是缺 DRAM，而是缺合格 HBM 系统件

HBM 的定价权来自 AI 加速器对本地带宽、容量和功耗的同时要求。传统 DRAM 周期仍重要，但 HBM 已经成为 memory supercycle 中最稀缺的高端切片。

核心判断

  1. 12026 年 HBM TAM 大概率落在 450-550 亿美元区间，取决于 Blackwell Ultra、Rubin 预备量、AMD MI350 和 ASIC 客户的放量节奏。
  2. 2HBM3E 仍是收入主力；HBM4 的重要性在于验证窗口、产品溢价和 2027 年 HBM4E/custom HBM 的先发位置。
  3. 3如果普通 DRAM 因供给挤压继续涨价，HBM 厂商会在高端 DRAM、server DRAM、HBM 间重新分配产能。

02 / Technology

HBM 的技术价值是把带宽贴近计算

HBM 不是 DDR 的线性升级。它通过 3D 堆叠、TSV、base die 和 2.5D 封装，把 DRAM 放到 GPU/ASIC 旁边，用宽总线换取 TB/s 级带宽和更低每 bit 能耗。

03 / Supply chain

三大厂竞争，胜负在量产质量和客户验证

HBM 的供应链不像普通 DRAM 那样只看 bit output。AI 客户需要稳定的整栈良率、热表现、功耗曲线和封装协同，任何一项掉链都会影响 GPU 或 ASIC 出货。

04 / Watch list

接下来 6-12 个月该看什么

HBM 的研究重点不只是规格表。真正有预测价值的是客户认证、封装分配、ASP 曲线和非 NVIDIA 需求的扩散。

Rubin HBM4 验证节奏

NVIDIA Rubin/Rubin Ultra 会决定 HBM4 首轮份额分配。谁先进供应链，谁就更可能在 HBM4E 和 custom HBM 里延续位置。

16-hi 良率

16-hi 带来更高容量，但热、翘曲和堆叠良率压力更大。它是容量增长的关键，也是供应商分化的地方。

CoWoS allocation

HBM 有货不等于 GPU 能出货。TSMC 先进封装、interposer 和系统级良率仍会约束 AI 加速器交付。

ASIC attach rate

Google TPU、AWS Trainium、Broadcom/Marvell custom ASIC 的 HBM 用量，会决定市场是否摆脱对 NVIDIA 单一节奏的依赖。

HBM3E ASP

成熟 HBM3E 供给改善后可能承压。若 HBM4 溢价不足，供应商盈利弹性会低于出货增速。

Custom HBM

base die 与客户 ASIC 的协同设计，会把 HBM 从标准品推向平台型组件，长期提高切换成本。
